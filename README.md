# architecture-repository

Architecture work for a self-directed learning programme (projects P1-P4): TOGAF **Preliminary Phase** artefacts, architecture principles, decisions (ADRs) and diagrams.

> Everything here is about a **fictional** organisation with **synthetic data only**.
> No employer information, no real systems, no real identifiers.
